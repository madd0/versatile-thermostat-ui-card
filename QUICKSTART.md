# 🚀 Quick Start

## For Users

Install via HACS → Add this repository → Install the card → See [README.md](README.md)

## For Developers

### GitHub Codespaces (Recommended)
```
Code → Codespaces → Create codespace
```
Everything auto-installs! Then run: `npm start`

### Local Setup
```bash
npm install
npm start
```

## Common Commands

| Command | Description |
|---------|-------------|
| `npm start` | Start dev server with hot reload |
| `npm run build` | Build for production |
| `npm run format` | Format code with Prettier |
